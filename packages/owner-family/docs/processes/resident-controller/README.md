# resident-controller: Docker-supervised trusted owner orchestrator

## Function and architectural application

Source/entry: `scripts/launch_resident_controller.py and scripts/build_resident_image.py`.

## Configuration and inputs

Qualified wheel, pinned bases, owner state mounts, private token and trusted Docker-socket authority.

## Readback and attribution

Source-matching ten-node/completed-boot readiness and recovered process after unexpected exit. Source custody and active runtime fingerprints identify the actual execution.

## Fit, case and field use

Retain execution across cloud task process loss while the Docker host and mounts remain available; never use as a customer sandbox.

## Operator guidelines

Read actual health after launch/recovery, retain state and credentials, and use the owning family supervisor. Actor results and independent production assessment are different evidence scopes.
