# Disconnect or reconnect this family pipeline

## Function and architectural application

Durably fence new gateway and bilateral actor admissions; preserve committed work and advance the generation on reconnect.

## User guidelines

Read successful acknowledgement. This affects this family only and does not firewall the host. Reauthenticate before explicit reconnect.

## Entry and expected context

`POST /api/web4/control {action: pipeline, connected: false, reason: owner isolation}`

## Fit, case and field use

Isolate one owner pipeline during incident response without deleting signed state.

## Supporting source and evidence

See `src/keddeh_namespace/web4_runtime.py`, the owner source manifest, process contracts and full qualification logs. The gateway accepts authenticated owner actions; customer frontage has a separate access boundary.
