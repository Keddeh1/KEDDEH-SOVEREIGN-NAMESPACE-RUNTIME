# Read actual runtime health

## Function and architectural application

Read workstation health/telemetry, current boot state and owned service PID status; a bound port alone is insufficient.

## User guidelines

Read after every start/recovery. Ten healthy workstations and current completed boot establish the local package readiness scope.

## Entry and expected context

`cloud status`

## Fit, case and field use

An operator distinguishes a live family from an open socket or bundled historical receipt.

## Supporting source and evidence

See `src/keddeh_namespace/web4_runtime.py`, the owner source manifest, process contracts and full qualification logs. The gateway accepts authenticated owner actions; customer frontage has a separate access boundary.
