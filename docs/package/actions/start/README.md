# Activate an admitted family

## Function and architectural application

Launch original broker, agent, MCP, HTTP actuator and workstations, read ten identities and wait for the current BOOT_SUBSTRATE completion.

## User guidelines

Use the repository launcher for repeatable startup and binding; it preserves mutable state and resumes admitted domains.

## Entry and expected context

`bash .keddeh/launch-family.sh`

## Fit, case and field use

Restart an evaluation environment while retaining signed namespace history.

## Supporting source and evidence

See `src/keddeh_namespace/web4_runtime.py`, the owner source manifest, process contracts and full qualification logs. The gateway accepts authenticated owner actions; customer frontage has a separate access boundary.
