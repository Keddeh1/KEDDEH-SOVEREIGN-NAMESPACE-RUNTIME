# Run current owner workbook diagnostics

## Function and architectural application

Invoke the supplied workbook_adapter.diagnostic_run and return fresh findings. Bundled historical receipts are not counted as current qualification.

## User guidelines

Review findings before expanding capabilities. Existing broader-estate missing-module findings remain visible rather than being suppressed.

## Entry and expected context

`cloud workbook`

## Fit, case and field use

Determine which parts of a supplied estate currently resolve in the admitted family.

## Supporting source and evidence

See `src/keddeh_namespace/web4_runtime.py`, the owner source manifest, process contracts and full qualification logs. The gateway accepts authenticated owner actions; customer frontage has a separate access boundary.
