# Run persistent bilateral execution

## Function and architectural application

With no enabled field, read retained cycle/pending/phase state. enabled=true resumes; false pauses while retaining unfinished intent. Every cycle consumes actual workstation/domain feedback and prior R36 returns.

## User guidelines

Use continuous execution when an owner family should power its own software control path. Confirm status=operating and returned actors; retrying/paused preserve diagnostic state.

## Entry and expected context

`cloud bilateral start | pause | status`

## Fit, case and field use

Resume an interrupted cycle after a controller restart without discarding a committed register prefix.

## Supporting source and evidence

See `src/keddeh_namespace/web4_runtime.py`, the owner source manifest, process contracts and full qualification logs. The gateway accepts authenticated owner actions; customer frontage has a separate access boundary.
