1. Engineering decision
The work contains two linked but non-interchangeable transactions. Track A is the immediate Squarespace-hosted DNS change that connects keddeh.com to the KEDDEH Sites surface. Track B is deployment of KEDDEH’s own authoritative namespace runtime and the later registrar delegation to it. Track A must not wait for Track B. Track B must not be simulated by adding nameserver labels to Squarespace.

8. Genesis IL-LLM execution model
Every root service is a genesis participant; no service is reduced to a disposable child.
Genesis participants converge into Genesis IL-LLM 1.
Each genesis participant launches exactly three child domains.
Each child returns exactly two independent front connections into the Genesis-1 backplane.
Genesis-1 is fed by the operator surface, layer 3, layer 2, genesis siblings and verified child returns.
Every participant subscribes to IL-LLM.
Production controls add explicit identities, signed immutable envelopes, bounded leases, replay protection, resource ceilings, spawn cooldowns, flywheel continuity, and wrapped-phase/ramped soft re-anchor. These controls implement the architecture without converting the 0.297 reference or health thresholds into unsupported claims.
9. Propagation logic
Forward: exact source → content hash → staged desired state → signed generation → ns1/ns2 replica → launched service → direct health/readback → archive generation → independent receipt.
Backward: live answer/service → runtime identity → generation receipt → parent stateRoot → exact source hash → source volume/configuration → author/verifier ledger.
stateRoot proves data state. phaseRoot proves synchronization state. They remain separate. Missing, divergent or unverifiable links keep the generation unpromoted.
10. Nameserver delegation decision boundary
DNS Settings edits the current hosted zone.
Nameserver Registration creates glue for in-bailiwick hosts.
Domain Nameservers changes delegation.
DNSSEC controls the registrar DS chain.
Do not change Domain Nameservers until ns1 and ns2 have stable public IPs, complete preserved zones, authoritative UDP/TCP answers, matching SOA serials, DNSSEC proofs, recursion refusal, and TSIG-protected transfers. If a DS already exists, coordinate removal/rollover so no stale DS makes the domain bogus.
dig @NS1_PUBLIC_IP keddeh.com SOA +norecurse
dig @NS2_PUBLIC_IP keddeh.com SOA +norecurse
dig +tcp @NS1_PUBLIC_IP keddeh.com DNSKEY +dnssec +norecurse
dig +tcp @NS2_PUBLIC_IP keddeh.com AXFR
The unauthenticated AXFR request must be refused.
