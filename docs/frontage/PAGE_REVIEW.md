# Route-by-route customer review

The review covers the entire existing candidate navigation, in manifest order. Proposed evaluation benefits are hypotheses to discuss, not measured customer outcomes.

## /

Audience and relevance: For teams investigating state continuity, runtime control or reproducible execution evidence.

Evaluation brief: Describe one workload, its current environment and the failure you need to recover from.

Architectural application: An evaluation brief can connect your required outcome to a named runtime, measured result and acceptance boundary.

Capture journey: Runtime evaluation through the existing interest form; explicit consent; private enquiry receipt.
